# font-renderer-from-scratch

YouTube チャンネル「車輪の再発明ラボ」で、C++ を使って、画面に文字を出す仕組み（フォントレンダラー）を一から作っている動画シリーズのコードです。
自分で描いたドット絵の文字から始めて、フォントファイルを読んで輪郭を塗り、日本語の文章を、拡大してもくっきり表示できるところ（SDF）まで進みます。フォントのファイルは配布していません。Windows に入っているフォントを、実行するときに読みます。

動画の公開に合わせて、回ごとにコードを追加していきます。

## 必要なもの
- Visual Studio Community（「C++によるデスクトップ開発」を入れたもの）

これだけで動きます。ほかのツールやライブラリは使いません。

## 動かし方
1. このページの緑色の「Code」ボタンを押し、「Download ZIP」を選びます。
2. ダウンロードした ZIP を右クリックし、「すべて展開」を選びます。
3. 見たい回のフォルダを開き、`.sln` ファイルをダブルクリックします。
4. Visual Studio が開いたら、F5 キーを押します。

## 游ゴシックが入っていないとき

第3回以降は、Windows の游ゴシック（`C:/Windows/Fonts/YuGothR.ttc`。第11回と第12回は太字の `C:/Windows/Fonts/YuGothB.ttc`）を読みます。游ゴシックが入っていない PC（英語版の Windows など）では、見たい回の `main.cpp` にあるフォントのパスを、`C:/Windows/Fonts/meiryo.ttc` など、その PC に入っているフォントに書き換えてください。メイリオも入っていない場合は、`C:/Windows/Fonts/` で別のフォントのファイル名を確かめます。

完成形や次の回では、Visual Studio の Ctrl+F で `font_path` を探すと、次の宣言が見つかります。引用符の中だけを変え、保存して F5 を押します。

```cpp
const char* font_path = "C:/Windows/Fonts/meiryo.ttc";
```

`ep03_start` には、まだこの宣言がありません。動画に合わせて、`main()` の「ここに、フォントを読む処理を書く」の場所へ宣言を書くときに、入っているフォントのパスを使ってください。読み込めるのは TrueType の輪郭を持つ `.ttf`・`.ttc` です。「あ」など日本語を描くときは、日本語の文字を含むフォントを選びます。対応する文字がないと、四角い代わりの文字になります。フォントのファイルはこのリポジトリに含めていません。

## フォルダの見方
各回のフォルダは、2つずつあります。

- `epXX_start` … その回を始める時点のコードです。動画を見ながら、ここから一緒に書き進められます
- `epXX_done` … その回を終えた時点のコードです。うまく動かないときは、こちらと見比べてください

前の回で詰まってしまっても、次の回の `_start` から合流できます。授業や勉強会の教材としても、自由に使ってください（MIT ライセンス）。
